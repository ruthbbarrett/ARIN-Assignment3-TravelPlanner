# ARIN-Assignment3-TravelPlanner
##Purpose 
An AI travel planning assistant that helps create and previse personalised itineraries. 

##Files 
'system-prompt.md': the complete system instructions for the planner including both the menu and activities. 

##What can the planner do: 
- it can plan a completely new trip: collects destination, duration, budget and incorporates your interests into the itinerary.
- revise and existing trip: either from the previous activity or a new trip pasted in.
- user can select one of the two features and switch to the other mid activity

##Limitations 
- only answers travel related questions
- does not carry out any booking procedures or offer options of flights or hotels
- AI can sometimes be wrong so details should be verified before travelling.
